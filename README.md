### About Me

I'm **MD Tufaful Ambia**, a **Full-Stack Web & Mobile App Developer** focused on engineering fast, scalable, and user-centric software—spanning responsive web platforms, cross-platform and native mobile apps, SQL/NoSQL backends, and offline-first business systems.

- 🔭 **Featured Work:** **[Shop Management Pro](https://github.com/tufaful/Shop-Management-Pro)** (Offline-First Web POS) & **[Tally Khata Pro](https://github.com/tufaful/Tally-Khata-Pro)** (Kotlin Mobile App)
- 📱 **Mobile & Web Craft:** Developing apps with **Flutter, React Native, Android (Java/Kotlin), React, Next.js, Laravel, Node.js, and Python**
- 🗄️ **Data & Architecture:** Designing reliable **SQL** (`PostgreSQL`, `MySQL`, `SQLite`) and **NoSQL** (`MongoDB`, `Firebase`, `Supabase`, `IndexedDB`) systems
- 💡 **Core Focus:** Clean UI/UX, bilingual (`EN / BN`) experiences, and practical software built for real-world operations
- 📫 **Reach Me:** [tufaful.inbox@gmail.com](mailto:tufaful.inbox@gmail.com)
