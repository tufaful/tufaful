### About Me

I'm **MD Tufaful Ambia**, a **Full-Stack Web Developer** focused on building fast, reliable, and user-centric web applications—from responsive interfaces to offline-first business software and cloud-synced systems.

- 🔭 Currently developing **[Shop Management Pro](https://github.com/tufaful/Shop-Management-Pro)** — an all-in-one, offline-first POS & business management web suite
- 🌱 Exploring **TypeScript, Progressive Web Apps (PWA), IndexedDB architectures, and Firebase cloud sync**
- 💡 Passionate about **clean UI/UX, bilingual (EN/BN) web experiences, and practical software for real-world businesses**
- 🤝 Open to collaborating on **full-stack web apps, business tools, and open-source projects**
- 📫 Reach me at **[tufaful.inbox@gmail.com](mailto:tufaful.inbox@gmail.com)**
